# Portfolio — React & Vite

A modern, animated, and responsive personal portfolio website built with React and Vite. Originally customized for **MD. Ashiqur Rahman**, a Biomedical Engineering student at Chittagong University of Engineering and Technology (CUET), Bangladesh.

This project can also serve as a starting point for students, developers, and professionals who want to create their own personal portfolio website.

🌐 **Live Demo:** https://animated-portfolio-main-zeta.vercel.app

## ✨ Features

- Modern design with smooth animations
- Responsive layout for desktop and mobile devices
- About, Skills, Education, Projects, and Contact sections
- Animated biomedical-themed hero illustration
- Customizable content, colors, and styling
- Built with React and Vite

## 🛠️ Technologies Used

- React
- Vite
- JavaScript
- CSS
- Lucide React

## 🚀 Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) before starting.

### Installation

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

### Production Build

To test a production build, run:

```bash
npm run build
```

## 🎨 How to Customize

Make this portfolio your own!

1. **Personal information:** Edit the relevant content in `src/App.jsx`.
2. **Projects:** Replace the example projects and interests with your own work, descriptions, technologies, and links.
3. **Profile photo:** Add your image to the `public` folder and update the corresponding image reference in the code.
4. **Colors and styling:** Modify the CSS files to change the theme, typography, spacing, and animations.
5. **Social links:** Replace the existing GitHub, LinkedIn, and contact links with your own.
6. **Education and skills:** Update the relevant sections to reflect your own background.

File names and component locations may vary if you modify the project structure.

## 🌍 Deployment

You can deploy your customized portfolio using [Vercel](https://vercel.com/).

1. Push your customized project to your GitHub repository.
2. Import the repository into Vercel.
3. Use `npm run build` as the build command.
4. Set `dist` as the output directory.
5. Deploy your website.
