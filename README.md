# Ashiqur Rahman — Portfolio

A responsive React + Vite portfolio for MD. Ashiqur Rahman, Biomedical Engineering student.

## What changed
- Removed the two scroll-controlled image-sequence sections.
- Replaced them with a lightweight animated hero illustration and CSS transitions.
- Updated the content to reflect the education and skills in the provided CV.
- Added About, Skills, Projects & Interests, Education, and Contact sections.
- Added responsive navigation and reduced-motion accessibility support.

## Run locally
Install Node.js (LTS), then in this folder run:

```bash
npm install
npm run dev
```

Open the local URL Vite prints in the terminal.

## Build for deployment
```bash
npm run build
npm run preview
```

The production website is created in `dist/`.

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep the framework preset as **Vite**.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Click **Deploy**.

## Before publishing
- Check every link and project description.
- Add links to specific repositories when you have projects you want to feature.
- Add a CV download only if you want to publish your CV publicly.
- No home address is displayed on the site.
